# Himark Foundation -- The Root Model

<!-- First draft. Working out the details in `docs/foundation/Lx_TEMP.md` -->

This document is the axiomatic floor of the language. Every construct, present or future, is expressible as a constructor over the one object defined here, or enters as a new axiom recorded here; nothing may redefine the object itself.

## Vocabulary and the object

Every term below is a universe object wearing a Himark role; terms are defined once, here, and every governed document uses them in exactly these senses.

- A **face** is a spelling in the role of naming one entry. **Fold** is the quotient constructor that lets several faces name one entry -- not the fold of functional programming: it collapses names into an identity, reducing nothing.
- An **alphabet** is a well-ordered set of entries, ordered by declaration; the word is set theory's, narrowed. It is virtual: denoted, never materialized.
- The **spelling order** is shortlex over spellings: shorter first, ties broken code point by code point. It is a well-order of type $\omega$ -- every spelling has finitely many predecessors and a successor -- and it is the one order every unbounded construct cuts.
- An **entry** is an individual member of an alphabet.
- A **universe** is *the object*, the only one the language has: a pointed alphabet, `<alphabet, value, face>` -- the alphabet with one distinguished position, `value` indexing the entry and `face` selecting one of its spellings. The point is present on every non-empty universe and absent on the empty one, where there is no entry to distinguish; that absence is the only nullability the object has. `value` and `face` are ordinals: the positional-value theorem below fixes how they compose, and over the floor both stay below $\omega^\omega$, plain naturals whenever the universe is finite.
- A **query** is a universe in the match role, used against text. It matches exactly one entry, by any face; a query denoting the empty universe matches nothing.
- A **capture** is a universe in the already-matched role. It is a derived value, never stored: an operand's universe and position name it exactly, so no operand carries a text field.

## The constructor floor

Five constructors, all total, build every universe:

- **Union** (`,`) appends an entry not yet present; a member whose spelling is already claimed contributes nothing (a no-op). Union is idempotent and associative, not commutative.
- **Subtraction** (`!{...}`) removes a present entry, and the set renumbers; a member naming no entry removes nothing (a no-op). Union and subtraction are dual: each is total by the same no-op rule over the same membership test.
- **Fold** (nesting as member) quotients spellings into one entry; a face whose spelling is already claimed drops from the fold (`{a,{a,A}}` holds two entries, the second spelled only `A`). Depth below the member flattens -- an entry is its flattened face sequence, claims applied in source order: `{a,{b,{c,C}}}` equals `{a,{b,c,C}}`.
- **Final segment** (`{a..}`) contributes every spelling from `a` onward in spelling order, each by the union rule. It is unary: an interval has two endpoints, a final segment has one cut. There is no right-hand side -- elided, defaulted, or infinite -- and no infinity token exists in the language; unboundedness is the absence of a second cut, not the presence of a limit object. The other constructors need no amendment: subtracting a final segment truncates, and a fold over one is a single entry wearing unboundedly many faces -- an entry, not an exception.
- **Product** (adjacency, `{cat}{dog}`) forms the universe whose entries are the tuples drawing one entry from each factor, spelled by concatenation and ordered most-significant-first by the positional-value theorem below. It is total: an empty factor yields the empty universe. Over finite factors it is compression -- the tuple alphabet is a flat universe one could have written directly -- but over an infinite factor it does not flatten (a product across an infinite factor need not be any spelling-order interval), so product is a constructor in its own right, the second admitted on the axiom side after final segment.

The constructors reach the **empty universe** (`{a,!{a}}`). It is legal, and a query denoting it matches nothing; emptiness is meaningless, not invalid, and meaningfulness stays an L2 concern. A bounded range whose lower endpoint exceeds its upper (`{z..a}`) denotes the standard empty interval; emptiness and unboundedness never share a spelling.

The source and AST are faithful -- nothing is rejected or rewritten at parse time. Normalization is the constructor semantics itself, applied wherever the universe is read, the same place subtraction has always resolved.

## Theorems, not axioms

These follow from the object and are never postulated separately:

- **Positional value.** The product orders its tuples most-significant-first: the tuple $p_0 \ldots p_{k-1}$ over factors of order type $b_0, \ldots, b_{k-1}$ sits at $\sum_i \mathrm{value}(p_i) \cdot (b_{i+1} \cdots b_{k-1})$ -- mixed radix on the value axis, the product order rather than an axiom. The face axis composes identically, mixed radix over per-entry face counts, so a tuple's faces are its positions' faces in order; both axes of a position are closed under product. Over finite factors the weights are naturals and the value is the familiar mixed-radix integer. Over an infinite factor the weight is that factor's order type, the sum is read in ordinal arithmetic with the weight on the left -- Cantor normal form when the type is $\omega$, multiplication no longer commuting -- and the value is an ordinal below $\omega^\omega$; the theorem does not change. The formula names a value for each *distinct* spelling, and concatenation is not injective -- `{a,ab}{c,bc}` spells `abc` from both `(a,bc)` and `(ab,c)` -- so where two tuples share a spelling the union no-op keeps the lower-valued one and drops the other. Position equals value exactly when the factor alphabets are uniquely decodable; the universe denotes faithfully either way, and only that identity, not the denotation, needs the side condition.
- **Bounded transfinitude.** The floor's order types are exactly the ordinals below $\omega^\omega$, closed under every constructor -- product multiplies them, union adds, fold and subtraction only shrink -- and $\omega^\omega$ is never reached, since every expression is finite. A single alphabet grown by union is $\omega$ plus a finite tail: each spelling below a cut has finitely many predecessors, so every member past a final segment adds finitely many entries. Product carries it higher -- `{b,c}{a..}` is $\omega \cdot 2$, `{a..}{a..}` is $\omega^2$ -- but no finite nesting escapes $\omega^\omega$. Order type alone disturbs nothing the matcher needs; decidability does, and it survives every constructor by the same fact read the other way: text is finite, so at any position only the finitely many faces no longer than the remaining text are candidates, whatever the order type above them.
- **Compression, not capability.** Bounded ranges (`{a..z}`), finite adjacency (`{cat}{dog}` = `{catdog}`), and splice (a spread form contributing a named universe's entries member by member) are notation for universes the floor already denotes. A bounded range is the difference of two final segments -- `{a..z}` is `{a..,!{s..}}` with `s` the successor of `z` in spelling order -- so ranges stay compression even with multi-spelling endpoints, and the interval is derived from the cut, never the reverse. Finite adjacency is the product constructor's compression, exactly as the bounded range is the final segment's. They compress the spelling; they add nothing to what a query can denote. Fold, final segment, and product-across-an-infinite-factor are not on this list: no arrangement of flat members makes two spellings share one value, no finite arrangement contributes unboundedly many entries, and no flat spelling-order interval reproduces a product over an infinite factor (`{a..}{b}` is `ab, bb, cb, ...`, not any interval) -- which is why each is a constructor and splice is not.

The re-admission test for any stripped or future construct: it enters either as **compression** (notation for a universe the floor already denotes) or as a **new axiom recorded above** -- never as a special case. Final segment and product are the constructs on the axiom side (recorded in the floor above); bounded ranges and finite adjacency are their compressions.

## North-star examples

Canonical floor denotations, kept in one place so every governed document stays consistent with them. Each row is illustration, not new axiom. The layer above extends this table in [L1_5.md](L1_5.md).

| Expression | Denotes |
| --- | --- |
| `{a,b,c}` | a, b, c |
| `{a..z}` | a, b, c, ..., z  (26 entries) |
| `{{cat,feline}}` | one entry, faces `cat` and `feline` |
| `{a..z,!{a,e,i,o,u}}` | b, c, d, f, ..., z  (21 consonants) |
| `{a..}` | a, b, c, ...  (final segment, order type $\omega$) |
| `{cat}{dog}` = `{catdog}` | catdog  (finite adjacency, one entry, compression) |
| `{a,ab}{b,c}` | ab, ac, abb, abc  (finite product, 4 entries; values 0, 1, 2, 3) |
| `{a,ab}{c,bc}` | ac, abc, abbc  (3 entries; `(ab,c)` re-spells `abc` at value 2 and drops) |
| `{a..}{b}` | ab, bb, cb, ...  (order type $\omega$; not a spelling interval, so not compression) |
| `{b,c}{a..}` | ba, bb, bc, ...; ca, cb, cc, ...  (order type $\omega \cdot 2$) |
| `{a..}{a..}` | aa, ab, ac, ...; ba, bb, ...  (order type $\omega^2$) |
| `{a,b,ab}` | a, b, ab  (three entries; values 0, 1, 2) |
| `{a,!{a}}` | {}  (empty universe) |
| `{z..a}` | {}  (reversed range = empty) |
