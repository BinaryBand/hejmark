# Himark L1 -- Mathematical Floor (denotation)

<!-- cspell:words shortlex transfinitude denotable unwritable recompact denotationally fixpoint -->

The axiomatic floor: the one object (a **universe**, written `<alphabet, <value, face>>`), the constructors that build it, and the theorems they force. L1 fixes which universes *exist* and how they compose. Using a universe against text (matching, query, capture) is L1.5 (L1_5.md). Nothing here rejects or interprets.

## Notation

Beyond the five constructors, every construct here is **sugar** -- compression that adds no power (proven under The theorems). All of it is declared in this table once; nothing later introduces notation absent from it. Expansions use the constructors and `C`, both defined below.

| Sugar | Expands to | Denotes |
| --- | --- | --- |
| `{x..y}` | the finite union of the spellings `x` through `y`, listed in shortlex order | spelling range -- with single-code-point endpoints, the code-point range |
| `C` | `{U+0000..U+D7FF, U+E000..U+10FFFF}` | the code-point set -- every scalar value, surrogates cut |
| `{cat}{dog}` | `{catdog}` | finite adjacency -- a finite product flattens |

- A range lists its members at expansion time: shortlex bounds every member's width by its endpoints', so the list is always finite.
- Endpoints are closure-free universes: `x` contributes its shortlex-least spelling, `y` its shortlex-greatest, and a lone spelling is the degenerate `x..x`. An empty endpoint, or `y` before `x`, lists nothing (`{z..a}`). Closure-free means finite, so a nonempty endpoint attains both ends; an unbounded endpoint (any closure) has no least-or-greatest to close the interval and so no reading. Hence no range is ever open: a universe that would need one is written from the closure directly (the numerals row in the witness table).
- Every row is finite. The closure is the only infinite construct, so no sugar ever carries an unbounded universe.
- `U+0000`-style hex names an atom directly -- the code point itself, not a universe: how these pages write atoms they cannot print, and the notation `C`'s own row above is written in. It stands wherever a character stands, so `{U+0061..U+007A}` is `{a..z}`.

## The building blocks

| Term | Is |
| --- | --- |
| **Alphabet** | an arbitrarily long, virtual list of abstract semantic concepts -- the entire virtual dictionary |
| **Entry** | one member of an alphabet, picked by `value` |
| **Face** | one spelling of an entry -- how it can be written, picked by `face` |
| **Universe** | *the object*, `<alphabet, <value, face>>` -- a "pointed alphabet": the alphabet plus a `<value, face>` pointer |

- **Spelling order** -- shortlex over spellings (shorter first, ties by code point). The code-point set is finite, so this is a well-order of type $\omega$. Two coordinates point:

  - `value` picks the entry: an ordinal below $\varepsilon_0$ -- a natural for a flat alphabet, mixed radix over a product's factors (positional value, below), below $\omega^\omega$ until closure goes nonlinear (bounded transfinitude, below).
  - `face` picks the spelling: an index into that entry's faces, **resting at 0** (the canonical face), non-zero only when a fold's later spelling hit.

  The pair `<value, face>` is the **capture**, carried at the floor, not bolted on above. A written universe leaves `value` free to range; matching (L1.5) binds `value` to one entry and `face` to the spelling that hit. `face` never changes the denotation -- every face names the same member -- so it rests where `value` ranges.

- **Claim rule** -- one law, obeyed by every constructor, stated once here. A spelling belongs to the **least `<value, face>` address that spells it** -- value first, face index to break the tie. Every later claimant loses that face; an entry that loses every face drops with them; both axes then renumber, surviving entries recompacting their values and surviving faces their indices, so the canonical face stays index 0. Fold, union, product, and closure all defer to this rule rather than carrying collision clauses of their own, and subtraction removes along the same two axes.

- **Code-point set** -- `C`, the atoms every face is spelled from: every Unicode scalar value (surrogates cut), a code-point range in the Notation above. `C` is the one seed the closure below closes over to generate every spelling, so the floor never needs a literal, entry-by-entry union of code points.

- **Empty universe** -- the empty alphabet (`{a,!{a}}`, or the empty member list `{}`), order type $0$: no entry, so no position to bind. Denotable; emptiness is meaningless, not invalid.

- **Unit universe** -- fold over the empty alphabet (`{{}}`), order type $1$: one entry, one face, the **empty spelling**. Zero *declared* faces is one empty face by stipulation, and the product identity below forces the stipulation: a faceless factor would zero the product's face axis, so `{{}}A` = `A` would fail there while holding on the value axis. The unit is the sole source of the empty spelling (shortlex's least element, unwritable as a token), the product's identity, and unmatchable -- L1.5 never accepts a zero-width span.

## The constructors

Five, all total; they build every universe. Totality: no constructor rejects, so every boundary case below -- the closure's included -- carries a denotation. The five at a glance, each detailed below:

| Constructor | Written | Builds |
| --- | --- | --- |
| **Union** | `,` | appends a universe's entries in order |
| **Subtraction** | `!{...}` | removes a universe's spellings from whatever claims them |
| **Fold** | `{...}` as member | quotients several faces onto one entry |
| **Product** | adjacency | entries are tuples, one per factor, spelled by concatenation, ordered by positional value |
| **Closure** | `&` | self-reference; the enclosing brace expression denotes its body's closure at $\omega$ |

- **Union** `,` -- append a universe's entries, in its order; a lone spelling is the singleton case. Contested spellings settle by the claim rule, so the earlier claimant keeps the spelling and the later one loses that face. Idempotent, associative, not commutative.

- **Subtraction** `!{...}` -- remove a universe's spellings from whatever claims them: each operand spelling strips the one face that claims it, and a spelling naming nothing removes nothing (the no-op). Dual to union: union settles a contested spelling in favour of the earlier claimant, subtraction removes a named spelling from its claimant; both act on spellings, entries leaving only as their faces do. On single-faced entries this is the familiar entry removal (`{a..z,!{a,e,i,o,u}}`); on a fold it is a face cut (`{{cat,feline},!{feline}}` is one entry spelled only `cat`), so the face axis has a constructor after all.

  Union and subtraction take a **universe** operand, not a spelling list, by axiom. Writing `N` for `{a,b,&{a,b}}` (the nonempty `ab`-strings, used throughout below), `{N,!{N{b}N}}` -- every nonempty `ab`-string with no interior `b`-seam -- removes infinitely many spellings at once, which no finite iteration of entry-wise steps reaches.

- **Fold** `{...}` as member -- quotient several faces onto one entry. Depth flattens: `{a,{b,{c,C}}}` = `{a,{b,c,C}}`, and a nested `{}` flattens to the unit's one face, the empty spelling. Total: over a denotationally empty universe it yields the unit, so `{{}}`, `{{z..a}}`, and `{{a,!{a}}}` are all the unit -- totality reads the operand's denotation, not its spelling.

- **Product** `{cat}{dog}` -- entries are tuples, one per factor, spelled by concatenation, ordered by positional value. Total (an empty factor gives the empty universe). Identity is the unit: a factor of order type $1$ wearing one empty face contributes no weight on the value axis and a factor of $1$ on the face axis, so `{{}}A` = `A` on both -- the theorem the surface's exponent `A^n` (L1.5) leans on to run down to `A^0`. Finite factors flatten (compression); an infinite factor does not, so product is a constructor, not notation.

- **Closure** `&` -- the self-reference token, legal wherever a member or factor stands. It binds to the innermost enclosing brace expression other than a subtraction operand (`!{...}`'s braces are the subtraction's own, never a binder site), and that expression denotes the **closure at $\omega$** of its body: stages $X_0$ the empty universe, $X_{k+1}$ = $X_k$ union the body with `&` read as $X_k$, entries ordered by first appearance -- stage-major, body order within a stage.

  A binder's braces are the closure's, not a fold's: used as a member the expression splices its entries, because closure is the union rule and union appends entry-wise -- to fold a closure, brace it once more. The union rule read at $\omega$: accumulation never retracts, so every body denotes. Three boundary bodies, all in the witness table: a subtracted `&` cannot oscillate, a bare `&` is the union no-op, and an unguarded fill converges because the claim rule strips each re-spelled face. One limit and no continuation past it: a body still producing at $\omega$ is cut there. Closure adds no collision clause -- the claim rule applies stage by stage.

## The theorems

Forced by the object, never postulated.

- **Positional value** -- a tuple $p_0 \ldots p_{k-1}$ over factor order types $b_i$ sits at $\sum_i W_i \cdot \mathrm{value}(p_i)$, summed most-significant term first with weight $W_i = b_{k-1} \cdot b_{k-2} \cdots b_{i+1}$ on the left of its digit: mixed radix. The face axis composes identically over per-entry face counts.

  The claim rule settles every collision this raises, with no clause added per axis:

  - Within one entry: two fills spell `0` at one value, the lower face index keeps it (the fill squared -- witness table).
  - Across entries: two tuples spell `abc`, the lower value keeps it (`{a,ab}{c,bc}`).
  - Cross-axis: the same rule -- with the warning that the dropped claimant can be an entry's *canonical* face, which then renumbers (`{{{},0}}{0,00}`).

  Finite factors give naturals, where the order of multiplication is invisible; an infinite factor gives an ordinal (Cantor normal form at base $\omega$), where it is load-bearing: $n \cdot \omega = \omega$ collapses any digit placed on the left. Rank equals value only when the factors decode uniquely: concatenation is not injective (`{a,ab}{c,bc}` spells `abc` twice), and membership survives the drop where rank and order type need not.

- **Canonical numerals** -- two orders meet on a radix's numerals closure, one free, one premised.

  **Free.** First-appearance order under the numerals closure is value order, for *every* radix. Stage-major accumulation walks the widths in order, and product order walks each width in value order; no premise about spellings is needed. This is the read L1.5's `where` leans on: the value line arrives in value order however the digits are dressed.

  **Premised.** Where every digit face is a single code point *and* the digits stand in code-point order (a bounded range is both by construction), value order and spelling order also agree on the canonical numerals of the radix. There is no leading zero digit, so the wider numeral is always the larger value; and within one width, positional order reads digit by digit -- exactly shortlex's tie-break. Only here does the value line arrive shortlex-sorted, and only here does a spelling range cut it exactly. Both premises bite: a digit wearing a wider face parts the two orders (L1.5's `{a,bb}` derivations), and so does a digit list out of code-point order, since within a width the string comparison reads codes where positional value reads positions.

- **Bounded transfinitude** -- order types are the ordinals below $\varepsilon_0$: closed under every constructor (union adds, subtraction shrinks, fold collapses to exactly one entry, product multiplies at most, closure sums $\omega$ stages, and collision only shrinks) and never reaching the bound, since every expression is finite. The bound is stratified:

  - Closure-free, the floor is finite: union, subtraction, fold, and finite product only rearrange finite lists, and every range lists finitely many spellings.
  - Linear closure -- at most one `&` per product, its co-factors finite -- reaches $\omega$ and stays below $\omega^\omega$: each stage multiplies the last by a finite on the right, so the limit is at most $u \cdot \omega$ for the base members' own bound $u$. Products of such closures climb -- `{b,c}N` is $\omega \cdot 2$ and `{b}N{b}N` is $\omega^2$ -- and finitely many factors keep every such product below $\omega^\omega$.
  - Nonlinear closure passes $\omega^\omega$. `{{(}{b}N{)},{(}&&{)}}` -- binary trees over $\omega$ leaves, parenthesized so no spelling collides -- squares its stage type each pass ($\omega, \omega^2, \omega^4, \ldots$), and its closure has type exactly $\omega^\omega$. Closures nested over it climb higher, and no finite expression reaches $\varepsilon_0$: a closure of stages below $\varepsilon_0$ stays below it, since stage types grow by ordinal sums and products alone, so the limit sits at $\omega^{\alpha \cdot \omega}$ for an $\alpha$ already under the bound.

  Collision alone does not decide the type: each drop keeps the least-valued split, and the surviving least splits do. In `{b}N{b}N` the seams collide (`babba` is both `b|a|b|ba` and `b|ab|b|a`), yet every pair with a `b`-free first segment is its own least split -- infinitely many full $\omega$-blocks survive, cofinally, so $\omega^2$ stands. In `NN` every split is legal, so the least split pins the prefix to a single character: only finitely many blocks survive, and the type collapses to $\omega \cdot k$ -- here $k = 2$, one block per character. (The matching consequence, decidability over finite text, is L1.5.)

- **Fixpoint on settled bodies** -- closure denotes on every body and earns its old name on the tame ones.

| Occurrence of `&` | Condition | What it buys |
| --- | --- | --- |
| **Positive** | no subtraction operand encloses it | the closure is the body's least fixpoint: every constructor is continuous in a positive slot, so the inflationary stages and the bare ones agree |
| **Guarded** | its product holds an `&`-free factor wearing no empty face | every pass lengthens every spelling, so a spelling of length $L$ settles -- present or absent -- by stage $L + 1$: membership is decided at a length-bounded stage |
| **Neither** | -- | still denotes, but only semi-settles: presence shows at some finite stage, absence carries no bound |

  Guarding is the decidability L1.5's matcher leans on. Unguarded and negative bodies denote all the same -- totality is the constructor's, not the fragment's. L1.5 classifies that boundary as the matcher's settled scope; refusing to match past it is L2's, not the floor's rejection.

- **Compression, not capability** -- the sugar (Notation) denotes only what the constructors already reach, adding no power. The closure of the unit under `C`, `{{{}},&C}`, is every spelling in shortlex -- stage $k$ the length-$(k-1)$ spellings, product order breaking ties code point by code point -- so the spelling order is generated, not postulated, and every range is a cut of it. The admission test: a construct enters as compression or as a new axiom, never a special case. Of the five, product and closure alone refuse compression: product over an infinite factor, and closure by power -- the finite constructors keep every closure-free universe finite, hence regular, while `{ab,{a}&{b}}` denotes $a^n b^n$, no regular face set, so no closure-free arrangement reaches it. Closure *can* escape regularity but need not: `{{{}},&C}` is regular. And no sugar ever needs the closure: every range is a finite shortlex interval, so ranges expand by union alone.

## Witness table

Writing `N` for `{a,b,&{a,b}}` throughout.

| Expression | Denotes |
| --- | --- |
| `{a,b,c}` | a, b, c |
| `{a..z}` | a, b, ..., z (26 entries) |
| `{{cat,feline}}` | one entry, faces `cat` and `feline` |
| `{a..z,!{a,e,i,o,u}}` | 21 consonants (difference = subtraction) |
| `{{cat,feline},!{feline}}` | one entry, spelled only `cat` (subtraction strips a face; the entry survives on its last spelling) |
| `N` = `{a,b,&{a,b}}` | a, b, aa, ab, ba, bb, aaa, ... -- the nonempty `ab`-strings (order type $\omega$) |
| `{N,!{N{b}N}}` | every nonempty `ab`-string with no interior `b`-seam (infinitely many removals: why the operand is a universe, not a spelling list) |
| `{cat}{dog}` = `{catdog}` | catdog (finite adjacency, compression) |
| `{a,ab}{b,c}` | ab, ac, abb, abc (values 0-3) |
| `{a,ab}{c,bc}` | ac, abc, abbc (`(ab,c)` re-spells `abc` at value 2, drops) |
| `N{b}` | ab, bb, aab, abb, ... (order type $\omega$; not a spelling interval) |
| `{b,c}N` | ba, bb, baa, ...; ca, cb, caa, ... (order type $\omega \cdot 2$) |
| `{b}N{b}N` | baba, babb, ...; bbba, bbbb, ... (order type $\omega^2$; seams collide, yet the type survives) |
| `NN` | aa, ab, aaa, ...; ba, bb, baa, ... (order type $\omega \cdot 2$, not $\omega^2$: every split is legal, so the least split pins the prefix to one character) |
| `{a,!{a}}` | {} (empty universe) |
| `{z..a}` | {} (reversed range) |
| `{{}}` | one entry, one face: the empty spelling (unit; `{{}}{cat}` = `{cat}`) |
| `{{{},0}}` | one entry, faces \`\` and `0` (the fill factor: fold of the unit with a spelling) |
| `{{{},0}}{{{},0}}` | one entry, faces \`\`, `0`, `00` (the fill squared; the two ways to spell `0` collide, the lower face index survives) |
| `{{{},0}}{0..9}` | 0, 1, ..., 9, each also faced `00`, `01`, ..., `09` (values unchanged; a face axis, not an entry axis) |
| `{{{},0}}{0,00}` | one entry faced `0`, `00`; one faced `000` (cross-axis collision: `00` is claimed by the lower value, so the higher entry loses its *canonical* face and renumbers) |
| `{a,&{b}}` | a, ab, abb, abbb, ... (closure, type $\omega$) |
| `{ab,{a}&{b}}` | ab, aabb, aaabbb, ... ($a^n b^n$: no regular face set -- closure's admission witness) |
| `{0,{1..9,&{0..9}}}` | 0, 1, ..., 9, 10, ..., 99, 100, ... (canonical numerals: first-appearance order is value order) |
| `{{{}},&C}` | \`\`, a, b, ..., aa, ab, ... (every spelling, in shortlex; `C` the code-point set -- the order every range cuts) |
| `{a,&}` | a (bare `&`: the union no-op; `{&}` is empty) |
| `{N,!{&}}` | a, b, aa, ab, ... (negative `&`: stage 1 places everything, every later body is empty -- no oscillation) |
| `{a,{{{},0}}&}` | a, 0a, 00a, ... (unguarded fill: each pass re-spells, the claim rule strips the claimed face, one new face survives) |
| `{ab,&&}` | ab, abab, ababab, ... (nonlinear, still type $\omega$) |
| `{{(}{b}N{)},{(}&&{)}}` | (ba), (bb), ..., ((ba)(ba)), ... (binary trees; type $\omega^\omega$ -- nonlinear closure passes the linear stratum's ceiling) |
