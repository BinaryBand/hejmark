## Permitted rewrites

A rewrite changes how an expression is computed, never what it denotes. Two families:
reach, which narrows a split search, and the value-cut collapse, which compacts a
single-digit cut.

### Reach -- the bound read off the expression

A factor wears no face longer than its expression reaches, so a split search offers it
no longer piece: the bound comes off the expression, never by streaming entries, and the
matches are identical -- only the cuts tried are fewer. Reach is a single code point or
range `1`, a literal its own length, a product the sum of its factors, and a final
segment or a closure `&` unbounded. `‸` marks the cut reach leaves.

| Query | On | Cut | Why |
| --- | --- | --- | --- |
| `{a..z}{0..9}` | `a5` | `a‸5` | each factor reaches 1 |
| `{cat}{0..9}` | `cat5` | `cat‸5` | `{cat}` reaches 3, pinning the head |
| `{{@a..z, &@a..z}}{!}` | `hello!` | `hello‸!` | `{!}` reaches 1, pinning the tail of the closure -- one probe, not six |

### Value-cut collapse -- a single-digit range cut is a range

Where value order and shortlex agree -- single-code-point digits -- a value cut of a
contiguous span is itself a contiguous range, so the digit-walk collapses to a literal
range. A cut that crosses into multi-digit numerals (`where aa..cc`) stays a walk.

| Expression | Rewrites to | Denotes |
| --- | --- | --- |
| `{a..z}[where c..g]` | `{c..g}` | c, d, e, f, g |
| `{0..9}[where 3..7]` | `{3..7}` | 3, 4, 5, 6, 7 |
| `{0..9}[below 3..7]` | `{3..6}` | 3, 4, 5, 6 |
| `{0..9}[where 7..3]` | `{}` | empty (hi below lo) |

## Refusals

The other half of the contract: where a read or a run cannot complete within a stated
bound, it is refused with a diagnostic rather than left to hang or guess.

| Run | Refused when | Diagnostic |
| --- | --- | --- |
| membership in an unguarded closure -- `{a, &}` on a non-member | no stage settles it, so absence has no bound | `HimarkUnsettledError` |
| a canonical `$0` or factor `$k` read | the wearer sits past the read budget | `HimarkScopeError` |
| a value cut `@lo..hi` over an unbounded head | the radix exceeds the digit budget | `ValueLineError` |
| a match or a contracting pass | it spends past the host's work budget | `HimarkBudgetError` |
| a contracting `<=>` pass | it fails to shrink the declared measure | `HimarkScopeError` |
| a document at ingest | it spells a noncharacter (the sentinel space) | `HimarkSentinelError` |

> Finish line: the contract holds when every read and every match the surface admits either completes within a stated bound or is refused with a diagnostic -- never a hang, never a guess.
