# Himark L2 -- Finite-Execution Contract (operational)

<!-- cspell:words noncharacter noncharacters shortlex Himark leftmost -->

L1 denotes totally and L1.5's surface adds no denotation, yet a host runs on finite text in finite time. This layer is the seam between the two: every place a total denotation meets a finite executor, and the refusal that keeps the meeting honest. It reads L1.5's constructs and adds none of its own -- a program admitted by L1.5 is well-formed, and this layer decides only whether it can be *run* within a bound, never whether it means something.

What belongs here is what the author of a program can observe. Three tiers divide it. A rule that changes *which programs are admitted* is normative: it decides whether a program is legal. A *cost* a run may not exceed without refusing is normative too: it decides whether a program finishes, which the denotation alone never says. A *rewrite* that preserves meaning is normative as a permission -- it is a theorem about the language, and L1's compression catalog is already exactly such a list, read for power where these are read for cost. What is left is *tactic*: which permitted rewrites a host takes, how it memoizes, how it sizes a budget. Tactics move a constant, a constant is not observable in the sense that matters, and they belong to the implementation. Bounds and permissions, never mechanisms -- a host that reaches the same bound by other means conforms.

## Bounded reads

- A value cut `@lo..hi` (and `where`, its pipeline spelling) reads the head's value line by a digit-walk over the head's digits. A bound the head radix does not spell is an L1.5 malformedness; a walk over an unbounded radix, or a read whose value runs past the host's budget, is refused here rather than streamed forever.
- A factor read `$1..$n` (and `$0`, the canonical read) is free where the hit's spelling splits one way. Where it splits many, the floor's collision rule decides the winner, but pricing that winner streams entries in value order -- refused past the host's budget rather than guessed. A back-referencing query rides the same machinery, each candidate split priced under its own bindings.
- The budget is the host's, not the language's: its existence is the contract, its size is a choice. A read inside the budget is exact; a read past it is a diagnostic, never a truncated guess.

## Decidable matching

The matcher is total on queries whose closure bodies are all guarded: the settlement theorem decides a length-$L$ spelling by stage $L + 1$, and finite text offers only finitely many candidate lengths, whatever the order type above. Closure-free queries are in scope by the same finiteness. An unguarded or negative body still denotes -- the floor's totality -- but only semi-settles: presence shows at some finite stage, absence carries no bound. Matching against it is out of scope, the one genuine residue of running a total floor on finite text, and a matcher run there is refused.

## Termination

The contracting statement `query <=>[@m] template` (L1.5 Emit) re-runs its pass until nothing rewrites, so it must be proved to stop. It stops because every pass strictly descends its declared measure: the document after the pass, read as spellings of `@m`, sits strictly earlier in `@m`'s entry order than the document before. Entry order is a well-order and a well-order has no infinite descent, so the passes settle -- the dual of a guarded body settling because every stage lengthens a spelling.

The measure is declared on the arrow, never inferred, and the host checks each pass, not the rule. A pass that fails to shrink the measure -- including one that only re-dresses an entry, since two faces of one entry sit nowhere earlier than each other -- is refused, as is a document the measure does not spell. The check never streams: enumeration is member-major, windows sit in spelling order, products run leftmost-slowest and closures stage-major, so which of two documents comes first is decided down the structure the stream would walk, an infinite stretch between them costing nothing.

## Cost

Decidability settles that an answer exists, not that it arrives. A procedure that is total but unaffordable hangs, and at the boundary a hang is indistinguishable from a wrong answer -- so the class is part of the contract, not a quality of implementation.

A guarded query against text of length $n$ is decided in time polynomial in $n$. The degree is a function of the query and never of the text -- a product of $k$ factors cuts the text at $k-1$ positions, and a guarded body settles a length-$L$ spelling by stage $L+1$ -- so no document turns an admitted query super-polynomial. Reaching that degree needs the observation under *Permitted rewrites* below, that equal membership questions have equal answers; a host that re-derives its subproblems instead exceeds the bound and does not conform, though which technique it uses to stay inside is its own business. A contracting statement is bounded per pass and not in total: descent proves the passes stop, but a well-order carries no numeral, so the pass count is finite with no bound stated in advance.

Polynomial is not the same as affordable, and no complexity class promises a wall clock. The budget rule of the reads therefore generalizes: the host holds a work budget over a match and over an iteration exactly as it holds one over a read -- its existence is the contract, its size is a choice -- and a run past it is a diagnostic, never a longer wait. That is what makes "never a hang" a property rather than a hope.

## Permitted rewrites

A host may replace an expression with any expression denoting the same universe, and a query with any query matching the same spans at the same positions. The permission is the normative part and the catalog is open; each entry is a theorem, so a rewrite enters here the way a construct enters the floor -- by proof, never by benefit. Two are worth naming, because the bound above is out of reach without them:

- A factor wears faces of bounded length wherever its expression is bounded, and the bound is read off the expression, never by streaming entries. No span longer than that bound can match, so none need be tried. Where the expression is unbounded -- a final segment, a closure -- there is no bound, and saying so is the correct answer rather than a failure to find one.
- Membership is a function of the expression, its environment, and the spelling, and of nothing else. Equal questions have equal answers, so an answer already derived stands in for deriving it again.

A rewrite that changes which spans match, or which programs are refused, is not a fast host but a wrong one, whatever it costs.

## Boundary hygiene

Sentinels are engine-private noncharacters and never cross the document boundary. A document that arrives spelling a noncharacter is refused -- Unicode reserves them against interchange -- and a sentinel surviving into the final document is a script error, a cleanup rule that did not fire, never something to strip silently. The cleanup itself is in-language (an ordinary `{@start,@end} => ""`); this layer only guards the two boundaries.

## Diagnostics

The operational refusals, each a well-formed program the host cannot run within its bound -- not an expression failing to denote, and not a surface malformedness (those are L1.5):

- a value read that runs past the host's budget, or a value cut over an unbounded radix;
- an ambiguous factor or `$0` split priced past the host's budget;
- a matcher run against an unguarded closure body;
- a match, or a pass of a contracting statement, run past the host's work budget;
- a `<=>` pass that fails to shrink its declared measure, or a document the measure does not spell;
- a noncharacter in the document at either boundary.

> Finish line: the contract holds when every read and every match the surface admits either completes within a stated bound or is refused with a diagnostic -- never a hang, never a guess.
