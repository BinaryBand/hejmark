# Himark L2 -- Standard Library (content)

<!-- Expandable layer. The floor is L1.md; the surface every entry is written over is L1_5.md. -->
<!-- cspell:words upto -->

L2 is nothing but in-language declarations over the L1.5 surface: `uni` universes and `:=` definitions. No host code, no new denotation, no new registers -- every entry compiles away through L1.5's expansion into the six constructors, which is the re-admission test in operational form.

That admission test is also why this layer is cheap. L1 and L1.5 carry the guarantees, so they change rarely and under scrutiny; an L2 entry is just a declaration, and adding one costs what writing it costs. If a candidate entry cannot be written -- its body needs a read no register provides -- that is an L1.5 question, where a new register faces the scrutiny a new axiom does, never something to patch here.

## The std

`C` is the code-point set of the source, seeded as a bounded range -- the one `uni` the host provides.

```text
uni hex         = {0..9,a..f}                                 -- the hex radix
uni spellings   = {{{}}, &@C}                                 -- every spelling, in shortlex
fill            := {{{}, @0}}                                 -- one entry, faced empty and zero
nonzero         := {@, !{@0}}
numerals        := {@0, {@nonzero, &@}}                       -- the value line of the head radix
shorter w       := {@spellings, !{@C^w @spellings}}           -- widths below w
upto w          := {@shorter w, @C^w}                         -- widths at most w
longer w        := {@spellings, !{@upto w}}                   -- widths above w
where lo..hi    := {@numerals, !{@numerals, !{ {lo..hi} }}}   -- the value line cut by a spelling range
pad w..w'       := {@fill^{w'} _, !{@shorter w}, !{@longer w'}}
```

`spellings` through `longer` are the width toolkit; `where` cuts the value line of the head radix by a spelling range (character radixes only, per L1_5.md's open list); `pad` is two face cuts over the fill. The derivations and the row-level ground truth live in L1_5.md -- this page only inventories what exists, and it is the inventory's home until the std ships as `.hmk` source the host loads.

## Adding an entry

- In-language only -- a new entry is a `uni` or `:=` declaration over the surface, nothing else.
- Expansion is admission -- if it expands into the six constructors, it enters; if it does not, it was never an L2 entry.
- Names are the interface -- entries reference each other by `@name`, acyclically, so any entry reads standalone by chasing declarations.

> Finish line: none -- the std grows entry by entry, and expansion is each entry's own admission test.
