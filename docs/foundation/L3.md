# Himark L3 -- Standard Library (content)

<!-- Expandable layer. The floor is L1.md; the surface every entry is written over is L1_5.md. -->

<!-- cspell:words upto padfree zfold shortlex noncharacters acyclically -->

L3 is the standard library: `uni` and `def` declarations over the L1.5 surface, nothing
else. No host code and no new denotation -- every entry expands into the five
constructors, which is its admission test. `char`, the one `uni` the host seeds, is the
floor's code points less the noncharacters (the sentinel space).

## The std

| Entry | Definition | Denotes |
| --- | --- | --- |
| `char` | *host-seeded* | the code points less the noncharacters -- the writable alphabet |
| `hex` | `{0..9,a..f}` | the hex radix |
| `str` | `{{{}},&@char}` | every spelling, in shortlex |
| `fill` | `{{{},@0}}` | one entry, faced empty and `@0` |
| `shorter w` | `{@str,!{@char^w@str}}` | spellings narrower than `w` |
| `upto w` | `{@shorter(w),@char^w}` | spellings of width at most `w` |
| `longer w` | `{@str,!{@upto(w)}}` | spellings wider than `w` |
| `where lo..hi` | `{@lo..hi}` | the head's value line, cut by value (open `0..` is all of it) |
| `below lo..hi` | `{@lo..hi,!{@hi}}` | that cut less its top endpoint (half-open `lo..hi`) |
| `pad w..w'` | `{@fill^{w'}_,!{@shorter(w)},!{@longer(w')}}` | each entry filled with `@0` to a width in `w..w'` |
| `zeros` | `{{{}},&@0}` | the `@0`-runs of the head, empty included |
| `zfold` | `{{@zeros}}` | one entry wearing every `@0`-run |
| `padfree` | `{@zfold_}` | every entry at every `@0`-padding |

## In action

| Expression | Denotes |
| --- | --- |
| `{0..9}[where 8..12]` | 8, 9, 10, 11, 12 |
| `{0..9}[below 8..12]` | 8, 9, 10, 11 |
| `{a..z}[where aa..cc]` | a, b, ..., z, ba, ..., cc (55 entries; aa = a = 0) |
| `{8,9,10,11,12}[pad 2]` | 88, 89, 10, 11, 12 (here `@0` = `8`) |
| `{0..9}[where 8..12 pad 1..2]` | {8,08}, {9,09}, 10, 11, 12 |

Entries reference each other by `@name`, acyclically, so any entry reads standalone by
chasing declarations. The derivations and row-level ground truth -- why each denotes what
it does -- live in L1_5.md; this page is the inventory.

> Finish line: none -- the std grows entry by entry, and expansion is each entry's own admission test.
