# Himark L3 -- Standard Library (content)

<!-- Expandable layer. The floor is L1.md; the surface every entry is written over is L1_5.md. -->

<!-- cspell:words upto padfree zfold noncharacters -->

L3 is nothing but in-language declarations over the L1.5 surface: `uni` universes and `def` definitions. No host code, no new denotation, no new registers -- every entry compiles away through L1.5's expansion into the five constructors, which is the admission test in operational form.

That admission test is also why this layer is cheap. L1 and L1.5 carry the guarantees, so they change rarely and under scrutiny; an L3 entry is just a declaration, and adding one costs what writing it costs. If a candidate entry cannot be written -- its body needs a read no register provides -- that is an L1.5 question, where a new register faces the scrutiny a new axiom does, never something to patch here.

## The std

`char` is the floor's code-point set `C` less the noncharacters -- the one `uni` the host provides. The noncharacters are L1.5's sentinel space, and subtracting them here is what keeps every `@char`-derived universe off them: `sentinel` declarations (L1_5.md) are host-seeded too, but they are per-script names, not std entries.

```text
uni hex          = {0..9,a..f}                                -- the hex radix
uni str          = {{{}},&@char}                              -- every spelling, in shortlex
def fill         = {{{},@0}}                                  -- one entry, faced empty and zero
def shorter w    = {@str,!{@char^w@str}}                      -- widths below w
def upto w       = {@shorter(w),@char^w}                      -- widths at most w
def longer w     = {@str,!{@upto(w)}}                         -- widths above w
def where lo..hi = {@lo..hi}                                  -- the value line, cut by value (open `0..` is all of it)
def below lo..hi = {@lo..hi,!{@hi}}                           -- the same cut, top endpoint dropped (half-open `lo..hi`)
def pad w..w'    = {@fill^{w'}_,!{@shorter(w)},!{@longer(w')}}
def zeros        = {{{}},&@0}                                 -- the zero-runs of the head, empty included
def zfold        = {{@zeros}}                                 -- folded: one entry wearing every zero-run
def padfree      = {@zfold_}                                  -- every entry at every zero-padding
```

`str` through `longer` are the width toolkit; `where` cuts the value line of the head radix by value, the value family's digit-walk making the cut exact over any radix, and `below` is that cut less its top endpoint, so a half-open span reads as one name rather than a hand-written band; `pad` is two face cuts over the fill; `zeros` through `padfree` are the uncapped pad. The derivations, the row-level ground truth, and why a `padfree` result matches but keeps no canonical read live in L1_5.md -- this page only inventories what exists, and it is the inventory's home until the std ships as `.hmk` source the host loads.

## Adding an entry

- In-language only -- a new entry is a `uni` or `def` declaration over the surface, nothing else.
- Names are the interface -- entries reference each other by `@name`, acyclically, so any entry reads standalone by chasing declarations.

> Finish line: none -- the std grows entry by entry, and expansion is each entry's own admission test.
